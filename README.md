# העוגן

אפליקציה למדריכות שפ"י בחירום: מתארים אירוע, מקבלים את התדריכים המאושרים המתאימים, וצ'ק ליסט של מה לעשות עכשיו.
עוצב ופותח על ידי חני בלוי.
