# תבנית גיליון האינדקס: העוגן

הגיליון הוא מקור האמת היחיד של האתר. מה שאין בגיליון, אין באתר.

## 1. הקמה (צעד אחר צעד)

1. ב-Google Drive: חדש ← Google Sheets. שם: `העוגן - אינדקס תדריכים`.
2. לשונית ראשונה: שני את שמה ל-`תדריכים`. הדביקי את שורת הכותרות מסעיף 2, כל כותרת בעמודה נפרדת.
3. לשונית שנייה: `קבועים`. שורת כותרות: `מפתח | ערך`.
4. הקפיאי את שורת הכותרות: תצוגה ← הקפאה ← שורה אחת.
5. פרסום כ-CSV: קובץ ← שיתוף ← פרסום באינטרנט ← בחרי לשונית "תדריכים" ← פורמט CSV ← פרסם. העתיקי את הקישור. חזרי על זה ללשונית "קבועים". שני הקישורים נכנסים לקוד פעם אחת.
6. שיתוף הגיליון עצמו: רק את (עורכת). לא לשתף "כל מי שיש לו קישור" לעריכה.

## 3. כללי מילוי

- **נקודה-פסיק (;) בין פריטים ברשימה.** לא פסיק, לא שורה חדשה.
- **מילות מפתח בצורת בסיס:** "תאונה" ולא "תאונות", "נהרג" ולא "נהרגה". המנוע מנרמל, אבל הבסיס הכי בטוח.
- **מילים נרדפות זה המקום לשפת השטח.** כאן שמים איך מדריכות באמת אומרות: "נפל", "הלך לעולמו", "אירוע רב נפגעים", "אזעקה".
- **עמודה O היא הלב.** רק ניסוח מהתדריך. אם התדריך כתוב לגוף שלישי ("המדריכה תוודא"), אפשר לעבור לגוף שני ("ודאי ש..."), בלי לשנות תוכן.
- **החלפת תדריך:** לא מוחקים את הישן. משנים F ל-`מוחלף`, ממלאים H במזהה החדש, ובחדש ממלאים G. האתר יראה את הישן מסומן ומקושר לחדש.
- **ארכיון:** תדריך שאין לו כבר שום תוקף ולא רוצים שיופיע גם כ"מוחלף". F = `ארכיון`. נעלם מהאתר, נשאר בגיליון לתיעוד.
