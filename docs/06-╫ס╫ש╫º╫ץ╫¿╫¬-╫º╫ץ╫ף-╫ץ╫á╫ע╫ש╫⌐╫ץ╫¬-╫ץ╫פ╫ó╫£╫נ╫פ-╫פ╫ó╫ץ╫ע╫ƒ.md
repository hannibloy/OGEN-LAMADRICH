# ביקורת הקוד מג'ימיני, בדיקות נגישות והעלאה לאוויר

## חלק א: שיחת ביקורת הקוד מג'ימיני

### הודעת פתיחה לשיחה (להעתקה)

```
שיחת ביקורת קוד לעוגן. הקובץ ogen-gemini.html מצורף לפרויקט. עבדי לפי מסמך 06 חלק א. אל תכתבי קוד עדיין. תני לי דוח ביקורת בלבד, ואחר כך נחליט מה משמרים ומה בונים מחדש.
```

### מה אני בודקת בקוד הקיים (דוח ב-5 חלקים)

**1. מה כדאי לשמור.** רכיבים שעובדים היטב: מבנה מסך, ניסוחים שאהבת, רעיונות UI. רשימה קצרה עם שורת הסבר לכל פריט.

**2. פערים מול האפיון (מסמך 02).** טבלה: דרישה באפיון | קיים / חסר / חלקי | מה נדרש.

**3. סיכוני תוכן.** האם יש בקוד תוכן מקצועי "מוטבע" (הנחיות, צ'ק ליסטים, טקסטים של תדריכים) שלא מגיע מגיליון? אלה נקודות שחייבות לצאת מהקוד ולעבור לגיליון, אחרת האתר יתקע בגרסה ישנה. האם יש קריאות ל-AI? אם כן, מסירים בשלב א'.

**4. סיכוני נגישות ומובייל.** ניגודיות, גדלי טקסט, `dir="rtl"`, labels, ניווט מקלדת, שימוש ב-localStorage (אינו עובד בתצוגה המקדימה של קלוד), ספריות חיצוניות כבדות.

**5. המלצה: לשדרג או לבנות מחדש.** דעתי המקצועית הכנה עם נימוק. ברירת המחדל שלי: אם יותר מ-40% מהמבנה צריך להשתנות, בונים מחדש ומעתיקים אליו את מה ששווה שמירה. בנייה מחדש על אפיון ברור זולה מתיקון קוד זר.

### ההחלטה שלך בסוף השיחה

אחת מהשלוש: "שדרגי את הקיים" / "בני מחדש ושמרי [רשימה]" / "רגע, יש לי שאלות". רק אחרי החלטה נפתחת שיחת בנייה.

## חלק ה: העלאה לאוויר (צעד אחר צעד)

1. **בדיקה מקומית:** פתחי את index.html מהמחשב בלחיצה כפולה. עובד? ממשיכות.
2. **GitHub:** היכנסי ל-github.com ← New repository ← שם: `haogen` ← Public או Private (Netlify עובד עם שניהם) ← Create. לחצי "uploading an existing file" ← גררי את: `index.html`, `_headers`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` ← Commit changes.
3. **Netlify:** Add new site ← Import an existing project ← GitHub ← בחרי `haogen` ← Deploy. תוך דקה יש כתובת `xxx.netlify.app`.
4. **בדיקה ראשונה באוויר** מהטלפון, לא מהמחשב.
5. **תת-דומיין:** ב-Netlify: Domain management ← Add domain ← `haogen.chanibloy.co.il`. Netlify יראה לך רשומת CNAME. אצל הרשם של הדומיין שלך: הוסיפי רשומת CNAME בשם `haogen` שמפנה לכתובת ש-Netlify נתן. עד שעה, ו-HTTPS מופעל אוטומטית.
6. **עדכון עתידי של הקוד:** גררי את הקובץ המעודכן לאותו ריפו ב-GitHub ← Commit. Netlify מתעדכן לבד. עדכון תוכן לא דורש את זה בכלל: רק הגיליון.
7. **הפצה למדריכות:** הודעת וואטסאפ קצרה עם הקישור והנחיה "הוסיפי למסך הבית". מומלץ לצרף צילום מסך של המסך הראשי.
