## חלק א: מה נעשה עד כה

### 1. בדיקת הקוד הקיים מג'מיני
- הקובץ שצורף לשיחה לא הכיל את קוד האפליקציה. הוא הכיל את מעטפת עמוד השיתוף של ג'מיני, ובנוסף עמוד השיתוף נחסם בידי מסנן התוכן ברשת.
- קישור שיתוף של ג'מיני מקפיא את השיחה ברגע השיתוף, ולכן ייתכן שהגרסה בגיטהאב אינה האחרונה.
- סוכם: חני מחלצת את הגרסה האחרונה מהשיחה המקורית בחשבון הג'מיני ומעלה לריפו `OGEN-LAMADRICH-GEMINI` בשם `ogen-gemini-latest.html`, לצד הקובץ הקיים, בלי לדרוס.

### 2. מיפוי תיקיית התדריכים בדרייב
בתיקייה הראשית נמצאו תיקיות משנה: אובדנות · גנים · הורים · צוות · תלמידים · פעילויות · צלח · עם כלביא · תכנית ביטחון · טפסים לפסיכיאטר/רווחה · תדריכים, מכתבים, הנחיות (עדכני), וכן קבצים בודדים ושני גיליונות קיימים.

נמצא גיליון קיים ומפורט: **"תדריכים_להעלאה_לגוגל_שיטס"** (כ-106 שורות) עם עמודות: נושא ראשי · תת-נושא · למי מיועד · שם התדריך · מילות חיפוש · צעדים מיידיים · קישור לדרייב · שם קובץ.

### 3. ממצאים בגיליון הקיים
- עמודת "צעדים מיידיים" אינה לקוחה מילה במילה מהתדריכים. חלקה תיאור של המסמך וחלקה סיכום מנוסח.
- אין עמודת תאריך ואין עמודת סטטוס, ולכן אי אפשר לדרג "עדכני ראשון".
- קישורים לדרייב חסרים כמעט בכל השורות.
- שתי שורות ללא קובץ, מסומנות "להוסיף תדריך ייעודי" (אמירות אובדניות בלי תכנון, פגיעה עצמית NSSI).
- מצגות מעורבבות עם תדריכים.
- כפילויות בדרייב: "ילד חולה" (פעמיים + גרסה לא סופית), עותקים בתיקיית גנים, וכשמונה גרסאות של מכתב להורים.

### 4. החלטות שהתקבלו
| נושא | החלטה |
|---|---|
| עץ הנושאים | העץ מהגיליון הקיים הוא הבסיס. נוספו שני נושאים ראשיים: גנים, הורים |
| עמודת "צעדים מיידיים" | נמחקת. שורות הפעולה נכתבות מחדש רק בשיחות התיוג, מתוך התדריך |
| סטודיו | גיליון נפרד |
| סוג פריט | נוספת עמודה חדשה (פירוט בחלק ב) |
| תדריך בשני נושאים | שורה אחת בגיליון, כמה נושאים ראשיים מופרדים בנקודה-פסיק |
| מצגות וסדנאות | יוצאות מגיליון התדריכים ועוברות לגיליון הסטודיו |

## חלק ב: טופס אפיון מעודכן

### 1. מבנה האפליקציה
מסגרת טלפון נייד, סרגל תחתון קבוע עם ארבעה כפתורים:

| כפתור | תפקיד |
|---|---|
| מה קרה? | תיאור חופשי + צ'יפים, תוצאות מדורגות, צ'ק ליסט (מסכים א-ג במסמך 02) |
| לפי נושא | נושא ראשי ← תת-נושא ← רשימת פריטים, מהחדש לישן. עד שלוש לחיצות |
| סטודיו | מצגות, סדנאות ופעילויות לשגרה, מגיליון הסטודיו |
| חירום | טלפונים ומידע קבוע מלשונית "קבועים" |

### 2. עץ הנושאים (8 נושאים ראשיים)
אובדנות · אבל ואובדן · מצוקה נפשית · מחלה ובריאות · אירוע ביטחוני · תרחישים קיצוניים · גנים · הורים

תתי-הנושאים של ששת הראשונים: כפי שהם בגיליון הקיים.

**גנים (הצעה לפי הקבצים בתיקייה, לאישור סופי בתיוג):**
1. שיחה עם ילדי גן בעקבות מוות
2. שיחה עם ילדי גן אחרי טראומה ואירוע ביטחוני
3. מכתב להורי הגן

**הורים (הצעה לפי הקבצים בתיקייה, לאישור סופי בתיוג):**
1. כתיבת מכתב להורים
2. שיחה עם הורה
3. סיוע להורים אחרי אסון

### 3. עמודת "סוג פריט" (חדשה)
רשימה סגורה, ערך אחד לכל שורה:

| ערך | מתי | האם יש "מה עלי לעשות" |
|---|---|---|
| תדריך | הנחיה מקצועית מאושרת | כן |
| צ'ק ליסט | רשימת פעולות מאושרת | כן |
| דף מסרים | מסרים בוני חוסן ודומיהם | לא, העמודה נשארת ריקה |
| מכתב לדוגמה | תבנית שהיועצת ממלאת ושולחת | לא, העמודה נשארת ריקה |
| טופס | מתוך תיקיית "טפסים לפסיכיאטר/רווחה" ודוח אירוע חריג | לא, העמודה נשארת ריקה |

שימוש באתר:
- בכל כרטיס מופיע תג קטן במילים עם סוג הפריט (לא בצבע בלבד, לפי דרישות הנגישות).
- במסך "לפי נושא" אפשר לסנן לפי סוג פריט.
- הצ'ק ליסט המאוחד נבנה רק מפריטים מסוג תדריך וצ'ק ליסט.
- סוג הפריט אינו משפיע על הניקוד.

## חלק ג: משימות פתוחות של חני
1. לחלץ את הקוד האחרון מהשיחה המקורית בג'מיני ולהעלות לריפו כ-`ogen-gemini-latest.html` (לפי ההנחיה שניתנה בשיחה).
2. להעלות את המסמך הזה לקבצי הפרויקט.
3. לחשוב אילו חומרי קנבה מתאימים לסטודיו (רשימה ראשונית מספיקה).

## חלק ד: סדר השיחות הבאות
1. **הכנת הגיליון** (השיחה הבאה): העברת הגיליון הקיים למבנה החדש, סימון כפילויות ושורות בלי קובץ.
2. **ביקורת קוד**: אחרי שהקובץ האחרון בריפו.
3. **תיוג** תדריך אחר תדריך לפי מסמך 05 (תאריך, סטטוס, מה עלי לעשות עכשיו).
4. **בנייה**, **נגישות**, **העלאה לאוויר**.
